## 원인 사슬
1. **프레임 의미 불일치 (guidance_node → pool_to_mission_quaternion 호출).** 난수 yaw 는 'pool 프레임 절대각' 이다.
   frame:=start_heading 에선 pool 측량이 없어 pool==odom==NED 북 이 되고, 노드가 헬퍼에 waypoint_frame='start_heading' 을
   넘겨 mission 쪽에서 start yaw 를 빼므로 결과는 **NED 절대 yaw ±30°** 가 된다. 기수가 북이면 티가 안 나고, 오늘처럼
   173° 면 147° 선회가 된다. 오프라인 재현: helper='start_heading' → start 대비 −147.4°, helper='ned' → **+25.9°** (의도).
   → 고칠 곳: guidance_node.py 의 pool_to_mission_quaternion(...) 두 호출(생성 시, mission frame 확정 시)에서
     start_heading 운용일 때 세 번째 인자를 'ned' 로. (guidance 는 이번에 수정하지 않음 — 사용자 지시.)
2. 147° slew 는 15 s, 다리는 6 s → slew 중에는 각속도 조건(5°/s) 때문에 reach 가 승인될 수 없다 → wp1 통과 → 벽.
   (목표가 ±30° 이내면 slew ≤3 s 로 상승 중에 끝나므로 이 게이트는 문제되지 않는다.)
3. 벽에서 전추력 중 EKF yaw reset 178° → 자세오차 170° → 정책 포화. 1차 시도(17:08/17:09)의 벽 구간 yaw 변화는
   자이로 적분과 일치(실제 회전)했으므로 reset 은 오늘 이 주행에서만 관측됨. 원인 후보: 전추력 전류의 자기 간섭.
