# sim2swim_paperfix_wa0017_mk2_s42_i299

Sim2Swim(arXiv:2512.08656) 재현 실패의 원인을 고친 첫 artifact.

## 무엇이 바뀌었나

논문 Table 1의 행동항 가중 **`w_a`를 0.3 → 0.017**로 낮춘 것 **외에 아무것도 바꾸지 않았다** —
plant, guidance, 관측 16-D, 적분 규칙, 도메인 랜덤화 모두 `paper_ref_v1` 그대로다.
관측/행동 계약도 동일하므로 `policy_node_mk2`가 그대로 로드한다.

## 왜

Eq.(6) 속도항은 `e^(-||o||^2)`라 오차 0 근방에서 기울기가 0인데, Eq.(8) 행동항은
`e^(-||a||)`로 제곱이 없어 **정상상태에서도 비용이 0이 되지 않는다.** 균형점을 정하는 값은
`A = drag(V_d)/K_surge` 하나다. 2026-08-28 수조 실측으로 `A = 0.486`(sim 계수와 1.8% 일치 —
plant는 맞았다). 그러면 보상최적 정상상태 추종률이 **20%**다. 정책은 고장난 게 아니라
주어진 보상을 정확히 최대화하고 있었다.

## 검증

| | w_a=0.3 (논문) | **이 artifact (w_a=0.017)** |
|---|---|---|
| 시드 재현율 (5시드) | 1/5 | **5/5** (추종률 표준편차 0.4) |
| Fig.4 (a) straight_line | 실패 | **통과** 85.7% (선회 제외 92.3%) |
| Fig.4 (b) square_ballast | 실패 | **통과** 93.2% |
| Fig.4 (c) square_random | 통과 | **통과** 94.2% |
| (a) cross-track 오차 | 1.85 m | **0.063 m** |
| 적분 포화 | clamp 5.0 도달 | **없음** (`pinned_fraction = 0`, 최대 1.6) |

행동 신호 전력의 98%가 0.5 Hz 이하다(5~12.5 Hz 0.4%) — T200 대역폭 14.5 Hz에 걸리는
성분이 없다. 크기 정규화한 변화율은 0.0148 → 0.0332(2.2배)로, 0.5 m/s를 내는 데 필요한
추력 증가에 따른 것이다.

## 실기 적용 전 주의

- **sim에서만 검증됐다.** 실기 시험 이력 없음.
- 속도 feedback은 여전히 ArduSub EKF3다. 논문이 쓰는 A50 DVL 직결 경로(layer 1)는
  기록만 구현돼 있고 feedback으로는 승격되지 않았다. 2026-08-28 수조 실측에서
  **EKF가 DVL 대비 12.9% 과소 보고**했고 heave 축은 **부호가 반대**였다.
- `w_a = 0.017`은 "추종률 90%" 목표를 역산한 값이라 그 자체로는 임의적이다.
  동적범위 균형은 `w_a ~ 0.115`(예측 49%).
