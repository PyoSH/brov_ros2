## 0. 상황과 청중

- 우리는 Sim2Swim(arXiv:2512.08656) 을 재현했다: IsaacLab 학습 → Gazebo SITL
  → 실기 BlueROV2 Heavy (Navigator FC, 수조 3.3×1.1×0.7 m).
- 저자들이 방문한다. 목표: (1) 재현 과정에서 찾은 것들을 공유, (2) 논문이
  다루지 않은 배포 지연 문제와 우리의 해법 논의, (3) 그들의 실기 경험과 대조.
- **가장 강한 카드**: 보상 계수 하나(w_a)가 추종 성능과 배포 안정성을 맞바꾸는
  **인과 사슬을 실측으로 완성**했고, 그 딜레마를 지연 DR 재학습으로 풀어 실기
  검증까지 마쳤다는 것.

## 1. 제안하는 발표 서사 (6 장)

### 장 1 — 재현: 되긴 되는데, 보상에 함정이 있다

- 논문 그대로 구현: 16-D 관측 [q_e, v_e^b, ω^b, z_v, z_q], BF-LOS guidance,
  DR(질량·부피·CoB), PPO. 학습 자체는 논문대로 재현됨.
- **발견 1 — w_a 딜레마.** 논문 값 w_a=0.3 으로는 추종률 **16.4%**
  (원인 분석: 정상상태에서 r_a = w_a·e^(−‖a‖) 가 0 이 안 되므로 균형점
  A = drag(V_d)/K 가 추종률을 결정 — 우리 plant 에서 A=0.495 → 이론 예측과
  실측 일치). w_a=0.017 로 낮추자 **100.0%**.
- 나중에 밝혀진 대가(장 3): 같은 관측점에서 순항 이득 K_p 가
  **1.3~1.6 (w_a=0.3) → 6~7 (w_a=0.017)** 로 4~5배 상승.
- 저자 확인 포인트: 그들의 실기에서 w_a=0.3 이 만든 낮은 이득이 "heave 응답
  느림"(논문 언급)의 원인 아닌지.

### 장 2 — 배포하니 떤다: 2 Hz, 3축, 포화

- SITL·실기 모두에서 재현: **2.0~2.3 Hz limit cycle**, 행동 포화
  surge 58% / sway 67%, 전진 0.10 m/s (목표 0.25).
- 배제한 가설 (각각 실험으로): 기체 공진(개루프에 2 Hz 없음), 적분기
  windup(클램프 점유 0%), deadband(동작점 밖), 관측 계단.
- **판정 실험 — 이득 ½ (A1)**: 진폭만 ×0.4~0.8, **주파수 불변** → 선형
  기전이면 꺼졌어야 함 → 포화(relay) + 지연의 limit cycle.

### 장 3 — 왜 떠는가: 지연 80 ms 의 위상 예산

- 정책 빼고 사각파 여기로 측정: **τ = 80 ms** (yaw, r=0.809; chirp 정밀화
  85.3 ms, lag 0 에서 상관 음수 = 지연의 존재 증명).
- 위상 예산 (2 Hz): 기체(관성) −90° + 지연 −57.6° + ZOH −14.4° ≈ **−180°**.
  이득 조건 |L|=K_p·SCALE/(m_eff·ω) > 1. 문턱: K_p < 3.5(τ=80).
- **IsaacLab 은 τ=0** → phase margin **+64° vs 실기 −24°**. 같은 이득(K_p≈4.5+)
  의 단순 P 제어도 같은 경로에서 1.99 Hz 로 동일하게 떤다(SITL 재현) —
  신경망 특유의 문제가 아니라 "지연 없는 세상에서 배운 이득"의 문제.
- 여기서 장 1 과 연결: **추종을 살린 보상 수정이 곧 배포 불안정의 원인** —
  w_a=0.3(안정하나 못 씀) ↔ w_a=0.017(추종하나 떤다) 딜레마.

### 장 4 — 지연은 어디서 오나: 분해 (M1~M4 + transit)

- 측정 4종: ping / TIMESYNC RTT / 명령→서보출력 / 서보→자이로(**FC 시계** —
  링크가 전혀 안 끼는 측정) + 메시지별 편도(transit, 시계 drift 보정).
- 결과: 링크 ~17 ms(테더 5.7 + 라우터) / **ArduSub 내부 ~40~58 ms** /
  액추에이터 **~0** (ESC 가설 기각 — RC_SPEED 상향 불필요 판정).
- FC = **Navigator** (ArduSub 가 RPi 에서 직접 돎, 직렬 링크 없음).
- **발견 2 — 위상 고정**: telemetry 25 Hz 와 제어 25 Hz 가 같은 주기라 대기가
  주행별 상수 [0,40 ms] 로 굳음 → τ 가 주행마다 50~112 로 달랐던 이유.
  telemetry 50 Hz 로 폭 절반(±10). 단 **surge 진동은 τ 평균에 둔감**.
- 온보드 이전·라우터 교체·DO_SET_SERVO 백엔드 전부 실측으로 기각
  (DO_SET_SERVO 는 실기에서 오히려 M3 60→140 ms).

### 장 5 — 해법: 지연을 학습에 넣는다 (지연 DR)

- 이론: 지연 d 는 관측을 비-Markov 로 만든다. 등가 정리(Katsikopoulos 2003):
  최근 행동 d 개를 관측에 붙이면 MDP 복원. 실증 전례: Tan RSS'18(지연 모델링),
  Imai'21 MMDR(**랜덤화 필수** — 고정 지연 학습은 분포 밖에서 급락), Sandha'21.
- 설계 A(16-D 유지 + 지연 40~80 ms 랜덤 + 관측 신선도 15%) vs
  설계 B(28-D = +행동 이력 2, MDP 복원).
- **단계 0 검증**: baseline + 주입 60 ms → IsaacLab 에서 2.28 Hz 재현(실기
  2.0~2.3 과 일치) — 인과 사슬이 통제 조건에서 닫힘. 주입값 보정도 검증
  (시뮬 액추에이터 모델이 이미 21 ms 등가 위상 공급 → 80 그대로 주입은 과잉).
- 결과: A 는 K_p 7.2→2.6(문턱 아래), 80 ms 에서 진동 1/14·포화 0%.
  B 는 60~80 ms 에서 A 보다 2~12배 우수 + 이력 Jacobian 음수("이미 보냈으면
  덜 민다") — 단 **학습 범위 밖 0~20 ms 에서 붕괴**(MMDR 의 교훈 그대로).
  배포는 계약 무변경인 A(delayA) 채택, fixplant 는 대조군 유지.

### 장 6 — 실기 검증과 남은 것

- **delayA 실기 A/B** (같은 자리·55 s 창): 포화 58→**7%**, v_e 평균
  −0.099→**−0.002**, 속도 +70%, 다리당 18.3→6.1 s. 50 Hz 에서 154 s/173 s
  무발산 청정 주행.
- **실기 순항점 Jacobian 확정** (청정 bag 재생 게이트 통과 후): surge 2.74 /
  sway 2.68 / heave 1.90 — 축별 문턱(3.71/3.84/3.52)의 **−26/−30/−46%**.
  IsaacLab 측정과 일치(동작점 우려 해소).
- 남은 것 셋: ① surge 2 Hz 6.5 N — 여유 최소 축(−26%)의 **저감쇠 공진 응답**
  (relay 아님: 문턱 아래·비포화·τ 둔감)으로 재해석, 재학습 목표는 감쇠 여유
  확대. ② 실기 재현의 실제 병목은 **DVL A50 간헐 불량**(바닥 고도 4 cm <
  최소 5 → 정지 lock 불가, 순항 valid ≥80% 가 정상 조건). ③ Case C
  (random_at_waypoint) 프레임 수정 대기.

## 3. 저자에게 물을 질문 (준비된 목록)

1. **실기 τ 를 재보셨는지, 진동을 보셨는지.** 우리는 80 ms + 2 Hz. 그들의
   스택(통신 경로)이 다르면 τ 도 다를 것.
2. **w_a=0.3 이 실기에서 만든 이득** — 우리 실측으로는 지연-안정권(문턱의
   절반 이하)이지만 추종 16%. 논문의 "heave 응답 느림" 이 그 저이득의 증상
   아닌지. 5-seed 결과에서 이득 분산은?
3. **행동 포화 비율** — 그들의 배포에서 |a|≥0.99 시간 비율.
4. sway–roll 커플링(측추력의 CoM 레버암)을 어떻게 다뤘는지.
5. Fig.4 의 통과 판정 기준(정량 지표)은 무엇이었는지.
6. DVL(A50) 운용 — 바닥 근접 lock, 간헐 dropout 을 겪었는지, EKF 게이트는.

## 5. 발표 팁

- **한 장짜리 요약 그림 제안**: x축 τ, y축 K_p, 문턱 곡선 K_thresh(τ) 하나
  긋고 — baseline(80,4.5~7 → 불안정영역), w_a=0.3(80,1.4 → 안정하나 추종
  불능 주석), delayA(80,2.6 → 안정+추종) 세 점. 이 그림이 장 1~6 을 관통한다.
- 정직성 유지: 우리가 틀렸다 정정한 것들(ESC 가설, baud 가설, SITL→실기
  DO_SET_SERVO 이전 실패)을 한 슬라이드로 — 저자 신뢰를 얻는 데 유효.
- surge 잔존은 미해결로 명시하고 재학습 계획(주입 중심 59 ms + Δa 벌점 A/B,
  기준선 사전 등록)으로 마무리.
